# ShopZone E-Commerce Template

A professional responsive e-commerce frontend inspired by the supplied mobile design.

## Features
- Responsive desktop/tablet/mobile UI
- Product search
- Category and product filters
- Product details modal
- Add to cart
- Quantity controls
- Automatic subtotal
- Wishlist
- LocalStorage persistence
- Newsletter form
- Mobile navigation
- Clean reusable JavaScript

## Run
Open `index.html` in a browser, or use VS Code + Live Server.

## Next backend step
Connect the frontend to Node.js/Express + MySQL or MongoDB for real authentication, products, orders and admin management.
